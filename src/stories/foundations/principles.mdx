# Aegis design principles

Aegis helps security analysts see what matters, understand the evidence, and act with confidence. Dense event data and AI assistance share a calm, consistent visual language.

## Float the workspace

The canvas gives every container breathing room. A surface holds content; a raised surface groups it; a floating surface carries persistent navigation or actions; an overlay presents a focused task. Borders and shadows work together in both themes.

<SurfaceExamples />

Keep navigation 12px from the top, left, and bottom of the viewport. Its radius follows its width: 8px when expanded to 240px, and 6px when collapsed to 48px. Expanded navigation uses 12px of interior padding; collapsed navigation uses 12px vertically and 4px horizontally, with 34px square icon rows. Keep the collapse or expand toggle at the top in both states. Other floating containers retain 20px of interior padding. Detail and assistant sheets float 12px from the top, right, and bottom, with an 8px radius. Cards use 16px padding; interactive rows use 8px corners.

Keep every radius at or below 8px. Control corners scale with their height: 28px controls use a 6px radius, 34px controls use 7px, and 40px controls use 8px. Chips and badges use rounded rectangular shapes with 6px corners; checkboxes keep 4px corners. These compact curves keep dense controls clear while borders and shadows establish the surface hierarchy.

## Give color a job

Neutral surfaces carry most of the interface. Function blue identifies the next action. A violet-to-blue gradient identifies AI assistance across filled, soft, and text treatments. Red marks destructive actions, green confirms success, and amber calls for attention. Severity is a separate scale: critical, high, medium, low, and informational. Pair color with a label or icon so meaning never depends on color alone.

## Preserve the analyst’s attention

Use a 14px interface base and a 13px dense-grid base. Keep timestamps, identifiers, host addresses, and code in JetBrains Mono. Align numeric values with tabular numerals. Grid rows measure 36px in compact density, 48px by default, and 60px in comfortable density. Use compact for rapid scanning and comfortable when secondary context needs room. Long alert titles stay on one line, with the full title available through the tooltip and accessible row label. Keep secondary metadata within the chosen row height. Density preserves the hierarchy and available actions.

<DensityExamples />

Use normal separators for clear boundaries and light separators for quieter grouping. A line divides sections; a dot separates short inline metadata. Both variants inherit semantic theme tokens.

## Make every path accessible

Every action has a visible label or accessible name. Focus uses the same 2px function-colored ring and 2px offset throughout. Keyboard users can enter and leave menus, navigate trees and grids, and complete dialogs. Restore focus after closing an overlay. Reduced-motion preferences remove decorative animation while preserving clear state changes.

## Guide multi-step work

The console opens rule creation with a vertical stepper so progress stays beside the active task. The reusable wizard also supports a horizontal layout. Keep completed steps revisitable, validate before advancing, and focus the new step heading. A sticky footer holds Back, Continue, and the final action; leaving a dirty workflow requires an explicit choice.

## Keep AI accountable

AI is an explicit intent with recognizable gradient treatments and the sparkles marker. Use the filled gradient for prominent AI actions, the soft gradient for quiet AI surfaces, and the foreground gradient for AI text. Generated content always carries an “AI generated” label. Show the context an assistant can access, link its claims to evidence, and distinguish confidence from certainty.

<AiLanguageExample />

Streaming must leave the interface usable: analysts can stop generation, inspect evidence, or continue working. Describe only work that actually occurred. The local mock says it scoped supplied evidence and prepared verification steps; a production adapter can report query results only after a query runs. Consequential changes require a human decision. Show the current and proposed rule together, provide explicit approve and reject actions, and record who approved the change.

Each assistant turn snapshots its evidence context. New selection cannot change an in-flight response, and regeneration reuses that original snapshot. Stop preserves partial output and returns focus to the composer. Late events from canceled or superseded streams are ignored.

The interactive examples use local, deterministic responses. They illustrate interaction behavior and do not connect to security infrastructure.
