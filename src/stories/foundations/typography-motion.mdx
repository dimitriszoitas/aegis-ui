# Type and motion

Figtree supports scanning across application interfaces. JetBrains Mono distinguishes code, identifiers, and machine-readable data. Both families are self-hosted, so interfaces do not depend on a font CDN.

## Typography

Fundamental and Fundamental Floating share typography. Interface text uses 14px, with 13px supporting text. Page titles use 26px; section and panel titles use 16px. Titles are semibold (600), while body text remains regular (400). Metric values use 28px with tabular numerals; their labels stay quieter. Reserve semantic color for values with meaningful status, not decoration. Sentence case keeps labels readable and direct.

The primitive type scale is available for custom compositions; semantic title and component roles define their actual application. Use JetBrains Mono for code, timestamps, addresses, and identifiers rather than for ordinary interface labels.

## Motion

Fast motion gives immediate feedback; base motion connects small state changes; slide motion introduces a sheet. Ease-out curves settle quickly. Sidebar width and padding transition over `--motion-fast` (120ms), from 240px wide with 12px interior padding to 48px wide with 12px vertical and 6px horizontal padding. Labels fade and clip without wrapping, and the toggle remains a stable target.

Fundamental uses edge-aligned navigation and workspace panels. Fundamental Floating contains navigation and assistant panels with rounded corners and exterior insets. Switching presentation keeps the same palette, typography, controls, content, and interaction state. Corner geometry is not animated.

Respect `prefers-reduced-motion` in every animation and transition. State changes remain clear when movement is removed. Loading and streaming indicators explain progress without preventing people from interacting with the rest of the workspace.
