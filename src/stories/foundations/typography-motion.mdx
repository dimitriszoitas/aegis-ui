# Type and motion

Inter supports fast scanning across a dense analyst workspace. JetBrains Mono distinguishes machine-readable evidence. Both font families are self-hosted, so documentation and product interfaces do not depend on a font CDN.

## Typography

Use 14px for the default interface and 13px for dense data grids. Titles progress through 16, 18, 20, 24, and 30px. Use 12px for supporting labels. Sentence case keeps labels readable and direct.

## Motion

Fast motion gives immediate control feedback; base motion connects small state changes; slide motion introduces a floating sheet. Ease-out curves settle quickly. Sidebar collapse animates width, padding, and radius together, from 240px wide with 12px interior padding and 8px corners to 48px wide with 12px vertical padding, 4px horizontal padding, and 6px corners. Its toggle stays at the top in both states, preserving a stable target. Sheets slide and fade.

<MotionExamples />

Respect `prefers-reduced-motion` in every animation and transition. State changes must remain clear when movement is removed. Loading and streaming indicators should explain progress without preventing analysts from interacting with the rest of the workspace.
